demo Java - Arduino - RF - STM32 - simu

STM32 : capabilite simu Apilot :
	nav reports "L %.2f %.2f \n", x, y
	commands sur 1 char du commit 802a39d
	demarrage auto

STM32 : capabilite radio (nucleo, bluepill)
	FINE TUNE code en dur, board #2 pour nucleo, board #6 pour Blue Pill
	RX : si msg de 2 bytes avec prefix '@' -> cmd 1 char pour Apilot
	     sinon CDC en format debug
	TX : les nav reports de Apilot, demarrage auto
	     message de test si commandes '!' ou '1' obtenues via CDC

STM32 : capabilite serial (teste sur nucleo, pourrait marcher sur bluepill)
	RX : modal, '#' pour toggle
		CDC_debug_mode = 1 : commandes de 1 char traitees par le simulateur (defaut) 
		CDC_debug_mode = 0 : commandes de 1 char traitees par demo CC1101
	TX : debug msg de demo CC1101 et simu

Arduino : capabilite radio
	FINE TUNE code en dur, board #1
	RX : reconnait les nav reports de Apilot, les envoie verbatim sur Serial
	     envoie les autres en format debug aussi sur Serial
	TX : emet seulement un texte de test sur ordre Serial type debug

Arduino : capabilite serial compatibilite Java commit f186030
	RX : si msg de 2 bytes avec prefix '@' -> radio
	     sinon cmd demo CC1101
	TX : nav reports format "L..." transmis au terminal Java qui plotte le vol
	     messages debug envoyes verbatim (ignores par Java regexp)
